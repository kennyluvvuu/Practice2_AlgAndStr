# Поиск подстрок в строке

Практическая работа №2 по алгоритмам и структурам данных. Модуль поиска подстрок и консольная утилита на основе алгоритма **Бойера-Мура-Хорспула (BMH)** с поддержкой цветного вывода и замера времени выполнения.

## Реализованный алгоритм

- **Бойера — Мура — Хорспула (BMH)** (алгоритм №5)

## Требования и установка

- Python >= 3.12
- [uv](https://github.com/astral-sh/uv) или стандартный `pip`

Установка через uv:

```bash
uv sync
```

Установка через pip и requirements.txt:

```bash
python3 -m venv .venv
source .venv/bin/activate  # Windows: .venv\Scripts\activate
pip install -r requirements.txt
```

> При использовании uv команды запускаются через `uv run ...`. При активированном venv — напрямую через `python ...`.

## Использование в коде

Функция `search` в модуле `search.py`:

```python
from search import search

# Поиск одной подстроки
result = search("ababbababa", "aba", case_sensitivity=False, method="first")
# (0, 5, 7)

# Поиск набора подстрок с ограничением count
result = search("ababbababa", ["aba", "bba"], method="first", count=3)
# {'aba': (0, 5), 'bba': (3,)}
```

Параметры функции `search`:
- `string`: исходная строка.
- `sub_string`: одна подстрока (`str`) или список/кортеж подстрок.
- `case_sensitivity`: чувствительность к регистру (по умолчанию `False`).
- `method`: направление поиска — `'first'` (с начала) или `'last'` (с конца).
- `count`: максимальное количество совпадений.

Повторяющиеся подстроки в списке учитываются один раз, поэтому дубликаты не увеличивают число совпадений.

## Консольная утилита

Запуск осуществляется через `main.py`:

```bash
# Поиск в строке нескольких подстрок
uv run python main.py -s "ababbababa" -p "aba" "bba"

# Поиск в файле с замером времени
uv run python main.py -f README.md -p "поиск" --show-time

# Поиск с конца с ограничением количества вхождений
uv run python main.py -s "ababbababa" -p "aba" -m last -c 2
```

### Параметры CLI

- `-s, --string` — строка для поиска.
- `-f, --file` — путь к файлу для поиска.
- `-p, --pattern` — одна или несколько подстрок для поиска.
- `--case-sensitive` — включить чувствительность к регистру (по умолчанию выключена).
- `-m, --method` — направление поиска: `first` или `last` (по умолчанию `first`).
- `-c, --count` — максимальное количество совпадений.
- `--no-color` — отключить цветное выделение в терминале.
- `--show-time` — выводить время выполнения поиска.

Вывод фрагментов текста ограничен первыми 10 строками с найденными совпадениями. Каждая подстрока подсвечивается отдельным ANSI-цветом.
